Why Beginners Struggle to Connect Code with Space Science

Current Barriers in STEM Education

  • Invisible Execution: Standard editors only print pass/fail; beginners never see how variables or lists evolve in memory.
  • Language & Setup Friction: Arabic-speaking learners face cryptic English tracebacks and complex local Python environments.
  • Static Toy Examples: Synthetic numbers fail to show how Python actually drives orbital navigation, Mars rovers, and planetary defense.

How Mr. Zero Solves It

  • 100% Real NASA Telemetry: Every lesson pulls live orbital velocities, Mars Curiosity REMS weather, NEO speeds, and Exoplanet Archive rows.
  • Arabic Error Explainer & Memory Board: Diagnoses exact tracebacks in Arabic and renders every variable type/value as live cards.
  • Zero-Setup Browser Lab: Runs locally via same-origin Pyodide WebAssembly; works on any school Chromebook or laptop without installs.

A Complete Interactive Coding & Visualization Environment

1. In-Browser Python 3.12

Executes Python code safely in the browser via locally served Pyodide 0.26.4 WebAssembly with ZIP header pre-verification and infinite-loop protection.

5. Zero Pro Study Suite

6. Click-to-Inspect Any Target

Clicking any of 29 celestial/mission models, near-Earth asteroids, or exoplanets loads its complete official NASA dossier, photo gallery, and runnable Python script.

ARCHITECTURE, LIMITATIONS & ROADMAP SLIDE 07 / 07

Engineering Stack & Path Forward

Production Tech Stack

  • Frontend: React 19, TypeScript, Vite 8, Tailwind CSS v4, Lucide Icons.
  • Python Runtime: Pyodide 0.26.4 (CPython 3.12 WebAssembly) served locally from Express.
  • Backend: Node.js 22 + Express server-side NASA API proxy & cache.

Known Limitations

  • Python runs on the main browser thread; while infinite loops (while True without break) are blocked before execution, heavy loops can briefly pause UI updates.
  • Rate-limited api.nasa.gov endpoints are safely cached and paired with keyless JPL/GSFC/Caltech endpoints.

Next Planned Milestones

  • Move Pyodide execution into a dedicated Web Worker with interruptible execution.
  • Add interactive matplotlib / NumPy spectral plotting modules for JWST & exoplanet light curves.
  • Classroom assignment export for Arabic STEM educators.
